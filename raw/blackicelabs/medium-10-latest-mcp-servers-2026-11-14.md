Explore some of the newest MCP servers that every AI developer should have on their radar.

MCP servers are making AI assistants much more powerful than simple chatbots. They allow AI tools to interact with applications, control devices, manage files, build projects, and perform tasks that would otherwise require manual work.

But there is something interesting happening: developers are building MCP servers for things I wouldn't have expected AI assistants to control.

Some can let AI interact with a real iPhone. Others can help build 3D scenes, design circuit boards, manage research papers, or even make multiple AI models debate a problem.

Here are 10 interesting MCP servers worth exploring if you want to see what AI agents can actually do.

## 1. Poki
What if you could ask your AI assistant to open an app on your iPhone, interact with its interface, and perform actions without touching the screen yourself?

That's what Poki is designed to make possible. Poki is an open-source project that allows AI agents to interact with a physical iPhone. Instead of relying entirely on simulated mobile environments, it connects your AI assistant to an actual device.

Your agent can interact with the phone, navigate applications, and perform supported actions through its interface. The interesting part is that it doesn't require jailbreaking your iPhone.

If you've ever wanted your AI coding agent to do more than just write code for an iPhone application, this is worth exploring.

GitHub: https://github.com/JosssphZhou/poki

## 2. Auto Ontology MCP
AI assistants can read documents and answer questions, but understanding how different pieces of information are connected is another challenge.

Auto Ontology MCP attempts to solve this problem. It helps AI assistants organize information into a structured knowledge base. Instead of treating every document or database table as an isolated source, it helps discover relationships between different pieces of information.

It can also help with database exploration, SQL validation, and organizing knowledge into an Obsidian-compatible vault.

Imagine connecting your project documentation and database information to an assistant that can understand how everything fits together.

GitHub: https://github.com/gogoymh/auto-ontology-mcp

## 3. Cheap Eyes
One problem with AI coding agents is that they can waste a surprising number of tokens reading large files.

Cheap Eyes takes an interesting approach to this problem. It allows your main AI assistant to delegate document-reading tasks to cheaper AI models. Instead of sending thousands of lines of logs or documentation to your expensive model, it can use a more affordable model to extract the information that matters.

It also checks extracted quotes and references against the original source, helping reduce mistakes.

Things making it useful are:
- Reading large documents without wasting expensive tokens.
- Extracting important information from logs.
- Searching through lengthy files.
- Reducing unnecessary context sent to your main AI model.

If you regularly work with large codebases, logs, or technical documentation, this is an interesting project to try.

GitHub: https://github.com/st412m/cheap-eyes

## 4. CodeBurn
If you regularly use AI coding tools, you probably know how quickly token usage and API costs can add up.

CodeBurn helps you understand where those resources are going. It tracks AI coding usage across tools such as Claude Code, Codex, Cursor, and Gemini. Through its MCP integration, an AI assistant can inspect usage information and help you understand your spending.

It can also help identify unnecessary usage from configured MCP servers and skills.

It can:
- Monitor AI coding expenses.
- Track token consumption.
- Compare usage across different coding tools.
- Identify unnecessary resource consumption.

Instead of manually checking different dashboards, you can ask your assistant to help investigate your AI coding usage.

GitHub: https://github.com/getagentseal/codeburn

## 5. Three-Live
Three.js is one of the most popular JavaScript libraries for creating interactive 3D experiences on the web. But what if an AI assistant could build a 3D scene and inspect the result itself?

That's where Three-Live becomes interesting. Three-Live is a project from Google that provides tools for working with Three.js projects. Its MCP integration allows AI agents to interact with the 3D development workflow.

Depending on the task, an agent can validate scenes, render images and animations, and inspect the output of a 3D project.

This could make working with 3D development much more accessible, especially for developers who want AI to help with both creating and checking their work.

GitHub: https://github.com/google/three-live

## 6. e3d-pilot
Most AI assistants rely on a single model to answer questions or make decisions. But what happens when you let multiple AI models examine the same problem?

e3d-pilot introduces an interesting approach. It allows an AI agent to send a question to multiple models, compare their answers, and let them challenge each other's reasoning. Rather than immediately accepting the first response, the system can use different perspectives to reach a more informed conclusion.

It also focuses on preserving decision history, making it easier to understand why a particular decision was made.

It compares answers from different AI models. It's particularly interesting for developers who want more than one AI opinion before making changes to a project.

GitHub: https://github.com/spacepacket1/e3d-pilot

## 7. MCP Zotero
If you work with research papers, academic references, or technical documents, Zotero is probably already familiar to you.

MCP Zotero connects AI assistants to your Zotero research library. This allows an assistant to search through references, retrieve research information, add papers using DOIs, and work with your existing collection.

It can also help with citations and importing research documents.

It can help with:
- Searching through research papers.
- Organizing academic references.
- Adding papers using their DOI.
- Working with citations while preparing documents.
- Finding relevant research without manually searching your entire library.

Imagine asking your AI assistant to find papers about a particular topic and organize the relevant references in your Zotero library.

GitHub: https://github.com/Xevos117/mcp-zotero

## 8. EDA Agent
AI coding assistants are becoming increasingly good at writing software, but what about designing actual electronic circuits?

EDA Agent is an interesting project that connects AI assistants to electronic design automation software. It aims to let agents work with tools such as Altium Designer, KiCad, and EasyEDA Pro.

Instead of simply asking an AI to explain how a circuit works, you can give it access to supported design operations.

It can help in:
- Working with electronic schematics.
- Modifying PCB layouts.
- Managing electronic components.
- Reviewing circuit designs.
- Automating parts of the electronics development process.

For electronics enthusiasts and hardware developers, this opens up some interesting possibilities.

GitHub: https://github.com/salitronic/eda-agent

## 9. Textbee MCP
Your AI assistant can already send emails, browse websites, and interact with APIs. But what if you wanted it to send an actual SMS using your own Android phone?

Textbee MCP makes that possible. It connects an AI assistant to a paired Android device, allowing it to interact with SMS functionality through the Textbee service. This means your assistant can send messages and retrieve SMS information using your connected device.

It can help with:
- Sending SMS messages through an Android phone.
- Retrieving messages.
- Managing connected devices.
- Building personal automation workflows.

For example, you could build an automation that sends an SMS notification when a particular event happens in one of your projects.

GitHub: https://github.com/textbee/textbee-mcp

## 10. SpeechWeave MCP
AI assistants are great at working with text, but audio files can be a little more complicated.

SpeechWeave MCP helps bridge that gap. It provides audio transcription capabilities through an MCP server. You can provide supported audio files or publicly accessible audio URLs and have them converted into text.

It also supports background transcription jobs, making it useful for longer recordings.

It can help you in:
- Transcribing audio recordings.
- Converting interviews into text.
- Processing meeting recordings.
- Working with longer audio files.
- Building audio-based automation workflows.

This is particularly useful if you regularly work with recordings and want your AI assistant to understand their contents without manually listening to everything.

GitHub: https://github.com/speechweave/speechweave-mcp

## Final Thoughts
MCP servers are evolving beyond simple integrations with databases, browsers, and APIs.

Projects like Poki show how AI agents can interact with physical devices. Three-Live brings AI into 3D development, while EDA Agent explores what happens when AI gets access to electronics design software, and that's what makes this ecosystem so interesting.

Developers are finding new ways to give AI assistants access to tools and environments that were previously outside their reach.

We are still early in this space, but I think the most interesting MCP servers will be the ones that allow AI agents to do things rather than simply provide answers.
